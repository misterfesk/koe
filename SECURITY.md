# Security

Koe handles personal, sensitive text, so security reports matter.

## Report a problem privately

Please do not open a public issue for a security problem.

1. Go to the **Security** tab of this repository on GitHub.
2. Choose **Report a vulnerability** (GitHub security advisories).
3. Describe what you found, how to reproduce it, and what it could expose.

Please include no real personal data in a report. Use test accounts.

This is an early preview maintained by one person. Reports are read as soon as possible, but there is no guaranteed response time and no bounty.

## What is most useful

- Ways to read or change another person's data.
- Ways to get free text sent to a model or search provider that should not be.
- Ways to bypass the safety check, the Help page or the usage limits.
- Leaked secrets in the repository or its history.

## Not a medical or emergency service

Koe is not for emergencies. If you or someone else is in danger, contact local emergency services or a crisis line.
